# FORMPILOT 4.0 — ULTIMATE HACKATHON EDITION
### Multilingual, Voice-Enabled Self-Learning Autonomous Browser Agent

> **FormPilot** is a multilingual, voice-enabled self-learning browser agent that discovers opportunities and government services, learns how websites work, reuses workflows with 4x speedup, recovers when websites change, and keeps humans in control of sensitive actions.

---

## 🌟 Core Loop & Architecture

```
USER
 ↓
VOICE (6 Languages) / TEXT
 ↓
AI TASK PLANNER
 ↓
WEB SEARCH / PORTAL DISCOVERY
 ↓
WEBCMD BROWSER AGENT (Live DOM + Cursor)
 ↓
EXPLORE & EXTRACT
 ↓
LEARN WORKFLOW SCHEMA
 ↓
REUSE (4.2x Fast-Path)
 ↓
VERIFY SOURCES (Anti-Hallucination)
 ↓
RECOVER IF MUTATED (94% Semantic Tree Heuristics)
 ↓
7-FACTOR ELIGIBILITY & SCORING (0-100)
 ↓
DOCUMENT INTELLIGENCE (Readiness Gauge)
 ↓
AI APPLICATION COPILOT
 ↓
🛑 STRICT HUMAN APPROVAL GATE
 ↓
TRACK & MONITOR (Immutable Audit Timeline)
```

---

## 🚀 Key Features

1. **AI Command Center**: Rotating prompt examples, quick action pills, floating multilingual voice assistant, and live agent topology graph.
2. **AI Task Planner**: Transparent, structured plan breakdown showing estimates, steps, and confidence.
3. **Live Browser Agent Sandbox**: Interactive viewport with real URL bar, live DOM inspector, cursor tracking, click ripples, and human takeover (`🖐 Take Control`).
4. **Self-Learning Workflows**: Automatically records successful navigation paths into reusable schemas with reliability metrics (96%).
5. **⚡ Zero-Shot Workflow Reuse**: Skips redundant web exploration when matching schemas exist in the cache.
6. **🔄 Self-Healing Recovery Engine**: Automatically heals broken selectors when websites rename buttons or change CSS hierarchies using semantic vector similarity.
7. **🎯 7-Factor Eligibility & Scoring**: Evaluates candidate fit across Degree, Branch, Year, Location, Skills, Stipend, and Experience + FormPilot Score (0-100).
8. **🔎 Source Verification**: Direct links, verified timestamps, and 1-opportunity-multi-source deduplication.
9. **🇮🇳 Indian Government Services Hub**: Dedicated integration with myScheme, National Scholarship Portal (NSP), and Karnataka State Scholarship Portal (SSP/Seva Sindhu).
10. **📋 Document Intelligence**: Readiness gauge (80%), missing document detector, and guidance.
11. **📝 AI Application Copilot & Human Gate**: Autofills complex portal essay questions; strictly enforces human review before submission.
12. **🎙️ Multilingual Voice Engine**: Speech-to-Text & Text-to-Speech in 6 languages: English, Hindi, Kannada, Malayalam, Tamil, and Telugu.
13. **🧪 Agent Chaos Test Lab**: 6 automated resilience scenarios (Button renamed, Jitter, Popups, Deprecated fields, Auth challenge).
14. **📊 Analytics & Health Score**: 96/100 Agent Health Gauge, success rate (96.4%), recovery rate (91.8%), and SVG activity curves.
15. **🎬 13-Scene Hackathon Demo Mode**: Automated 13-scene interactive presentation walking through the complete product story.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS
- **Icons & UI**: Lucide React, Canvas Confetti
- **Voice Engine**: Web Speech API (SpeechRecognition & SpeechSynthesis) with native multilingual accent mappings and Web Audio API tone synthesis
- **State & Sandbox**: Custom Reactive Agent State Machine with local persistence

## 📦 Quick Start

```bash
# Clone the repository
git clone https://github.com/albin669-gif/Formpilot4.0.git
cd Formpilot4.0

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```

Open `http://localhost:5173/` in your browser.
Click **`🎬 HACKATHON DEMO`** in the top bar to run the automated presentation!
